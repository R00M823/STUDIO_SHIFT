# STUDIO SHIFT

シフト作成サポートツールのプロトタイプです。

## 実行方法

1. このリポジトリをローカルにクローンします。
2. ブラウザで `index.html` を開きます。
3. スタッフ情報を編集し、「シフト自動生成」を実行します。
4. CSV出力でSpreadsheetへ展開できます。

## 実装内容

- スタッフ情報の入力
- 月間シフトの自動割り当て
- 希望休重視の休み確保
- 3連勤制限の簡易チェック
- 最低人数アラート
- CSV出力

## 制約

- この版は完全ローカルブラウザ向けのプロトタイプです。
- 本番向けには、より高度な最適化とデータ保存機能の追加を想定しています。
